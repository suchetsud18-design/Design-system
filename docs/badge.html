Badge

Displays a small status label or category tag. Inline, pill-shaped, and available in four variants — default, secondary, outline, and destructive.

Usage — shadcn/ui

# Install via shadcn/ui CLI
npx shadcn@latest add badge
import { Badge } from "@/components/ui/badge"

export function BadgeDemo() {
  return (
    <div className="flex gap-2">
      <Badge>Default</Badge>
      <Badge variant="secondary">Secondary</Badge>
      <Badge variant="outline">Outline</Badge>
      <Badge variant="destructive">Destructive</Badge>
    </div>
  )
}

// As a link (asChild pattern)
import { Link } from "next/link"

<Badge asChild>
  <Link href="/changelog">What's new</Link>
</Badge>

Props

PropTypeDefaultDescription
variant"default" | "secondary" | "outline" | "destructive""default"Visual style of the badge.
asChildbooleanfalseRenders the badge as a child element (Radix slot) — useful for rendering as <a> or <Link>.
classNamestring—Additional CSS classes merged via cn().
childrenReactNode—Badge label content. Can include icons alongside text.

Badge extends all standard HTMLDivElement attributes (e.g. onClick, aria-label).

Accessibility

Badge renders as a <div> by default — purely visual. Add semantic markup when the badge conveys meaningful status.

PatternGuidance
Status labelUse role="status" or wrap in a <span> with aria-label when the badge communicates a live state (e.g. "3 unread").
DecorativeIf the badge duplicates information already present in text, add aria-hidden="true" to avoid redundant announcements.
Interactive badgeUse asChild with an <a> or <button> so the element is natively focusable and keyboard-operable.
Color contrastAll four variants meet WCAG AA (≥ 4.5:1) for normal text. Destructive white-on-red achieves 5.25:1. Outline dark-on-white achieves 15.8:1.
Count badgesProvide a visually hidden label: <span class="sr-only">12 notifications</span> alongside a numeric badge.
