Dropdown Menu

Displays a menu to the user — such as a set of actions or functions — triggered by a button. Built on Radix UI Dropdown Menu.

Accessibility

Keyboard & ARIA

  • ↑ / ↓ — Move focus between menu items.
  • Enter / Space — Activate focused item.
  • Escape — Close the menu and return focus to trigger.
  • Trigger has aria-haspopup="menu" and aria-expanded.
  • Menu uses role="menu"; items use role="menuitem".
