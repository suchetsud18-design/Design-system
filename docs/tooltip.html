Tooltip

A popup that displays information related to an element when the element receives keyboard focus or the mouse hovers over it. Built on Radix UI Tooltip.

Accessibility

Keyboard & ARIA

  • Tooltip appears when trigger receives focus via keyboard — no hover required.
  • Escape — Closes the tooltip.
  • Content uses role="tooltip" and the trigger references it via aria-describedby.
  • For icon-only triggers, add aria-label to the trigger for screen reader announcement.
