Component

Breadcrumb

Displays the path to the current resource using a hierarchy of links. Supports slash and chevron separators, a collapsible ellipsis for deep paths, a dropdown trigger on any segment, and a responsive variant.

Accessibility
ConcernGuidance
LandmarkThe root element renders as <nav>. Always provide a unique aria-label (e.g. aria-label="breadcrumb") so screen readers distinguish it from other nav landmarks.
List semanticsBreadcrumbList renders as <ol> — ordered, because the hierarchy is meaningful. Each item is a native <li>.
Current pageBreadcrumbPage automatically adds aria-current="page" and role="link" so screen readers announce it as the active location.
SeparatorBreadcrumbSeparator adds aria-hidden="true" — it's presentational and should never be read aloud.
EllipsisBreadcrumbEllipsis renders as a <button> with an aria-label such as "Show hidden pages". Keyboard users must be able to activate it with Enter / Space.
DropdownWhen using a DropdownMenu inside a breadcrumb item, ensure aria-haspopup="true" and aria-expanded are correctly toggled. Focus must return to the trigger on close.
Link vs spanAll ancestor segments must be true <a> elements — not buttons or spans — so they're reachable by keyboard Tab and have understandable link semantics.
