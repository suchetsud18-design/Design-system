How CSS custom properties, Figma tokens, and dark mode fit together — and how to override anything.

How CSS variables work

All color tokens are stored as bare HSL triplets — three numbers separated by spaces, with no hsl() wrapper.

cssdesign-tokens.css
/* Figma Variable: Shadcn/ui/primary → neutral/900 → #171717 */
--primary: 0 0% 9%;             /* H S% L% — no hsl() wrapper */
--primary-foreground: 0 0% 98%;  /* #fafafa */

Separating the triplet from the hsl() function is what makes arbitrary opacity composition possible anywhere in your CSS and Tailwind classes — no extra token needed for each opacity step:

css
/* Full opacity — standard use */
color: hsl(var(--primary));

/* 50% opacity — no extra token needed */
color: hsl(var(--primary) / 0.5);

/* 10% opacity overlay */
background: hsl(var(--primary) / 0.1);

/* Tailwind — same syntax via tw arbitrary values */
<div className="bg-[hsl(var(--primary)/0.1)]" />

Option A — next-themes (recommended)

bash
npm install next-themes
tsxsrc/app/layout.tsx
import { ThemeProvider } from 'next-themes'

export default function RootLayout({
  children,
}: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body>
        <ThemeProvider
          attribute="class"
          defaultTheme="system"
          enableSystem
        >
          {children}
        </ThemeProvider>
      </body>
    </html>
  )
}
Why attribute="class"? next-themes adds a class (dark) to <html>. Our token file uses :root.dark to match this — so no extra configuration is needed.

Option B — manual data attribute

If you prefer not to use a library, toggle the attribute directly on the <html> element.

typescript
// Toggle dark mode
document.documentElement.setAttribute('data-theme', 'dark')

// Toggle light mode
document.documentElement.setAttribute('data-theme', 'light')

// Or use the class
document.documentElement.classList.toggle('dark')

Customizing tokens

Override any token by re-declaring it in your globals.css after the import. You never need to edit design-tokens.css directly — it should be treated as a generated file.

csssrc/app/globals.css
@import '../styles/design-tokens.css';

@tailwind base;
@tailwind components;
@tailwind utilities;

/* Brand overrides — applied after the token file */
:root {
  /* Swap primary to a brand blue */
  --primary:            221 83% 53%;
  --primary-foreground: 0 0% 100%;
  --primary-hover:      221 83% 45%;
  --primary-active:     221 83% 38%;

  /* Sharper border radius */
  --radius-sm: 0.125rem;
  --radius-md: 0.25rem;
  --radius-lg: 0.375rem;

  /* Custom brand font */
  --font-sans: "DM Sans", ui-sans-serif, system-ui, sans-serif;
}

/* Dark mode overrides */
:root.dark {
  --primary:            213 94% 68%;
  --primary-foreground: 0 0% 9%;
}
Keep both modes in sync. When you override a light mode token, always add a matching dark mode override. A --primary that looks great at 221 83% 53% in light mode is likely too bright in dark mode without adjustment.

Component-level tokens

Some components expose their own tokens that alias the global ones. These let you tune individual components without touching global values.

cssdesign-tokens.css (excerpt)
/* Button component tokens */
--button-height-sm:     2rem;
--button-height-md:     2.5rem;
--button-height-lg:     2.75rem;
--button-padding-x-md:  1rem;
--button-font-weight:   var(--font-medium);
--button-radius:        var(--radius-md);

/* Input component tokens */
--input-height-md:      2.5rem;
--input-padding-x:      0.75rem;
--input-radius:         var(--radius-md);

/* Card component tokens */
--card-padding:         var(--space-6);
--card-radius:          var(--radius-lg);
--card-shadow:          var(--shadow-sm);

To make all buttons taller with rounded corners without changing any other component, override only the button tokens:

css
:root {
  --button-height-md: 3rem;
  --button-radius:    var(--radius-full);   /* pill shape */
}

Beyond color

The token file covers far more than color. Every spatial and typographic decision in the system is a token.

Typography
Font family, size (xs–9xl), weight (100–900), line height, and letter spacing — all from Figma.
--font-sans, --font-mono
--text-xs → --text-9xl
--font-normal → --font-bold
--leading-3 → --leading-10
--tracking-tighter → --tracking-widest
Spacing
A 4px-base scale from 0 to 96 (384px). Used for padding, margin, and gap throughout.
--space-0 (0px)
--space-4 (16px)
--space-8 (32px)
--space-16 (64px)
--space-96 (384px)
Border Radius
Ten steps from none (0) to full (9999px), matching Tailwind's scale exactly.
--radius-none (0px)
--radius-sm (4px)
--radius-md (6px)
--radius-lg (8px)
--radius-full (9999px)
Animation
Duration (75ms–1000ms) and easing functions for all transitions and animations.
--duration-150 (150ms)
--duration-300 (300ms)
--easing-out
--easing-in-out
--easing-bounce
