Component

Toggle Group

A set of two-state buttons that can be toggled on or off. Supports single and multiple selection modes. Built on Radix UI Toggle Group.

Preview
Text alignment — single selection
Text format — multiple selection
Usage
import { ToggleGroup, ToggleGroupItem } from "@/components/ui/toggle-group" // Single selection <ToggleGroup type="single" defaultValue="left"> <ToggleGroupItem value="left">Left</ToggleGroupItem> <ToggleGroupItem value="center">Center</ToggleGroupItem> <ToggleGroupItem value="right">Right</ToggleGroupItem> </ToggleGroup> // Multiple selection <ToggleGroup type="multiple"> <ToggleGroupItem value="bold"><Bold className="h-4 w-4" /></ToggleGroupItem> <ToggleGroupItem value="italic"><Italic className="h-4 w-4" /></ToggleGroupItem> </ToggleGroup>
Props
ComponentPropTypeDescription
ToggleGrouptype"single" | "multiple"Selection mode.
ToggleGroupvaluestring | string[]Controlled value.
ToggleGroupdefaultValuestring | string[]Initial value (uncontrolled).
ToggleGrouponValueChangefunctionCallback when selection changes.
ToggleGroupItemvaluestringUnique value for this item.
ToggleGroupItemdisabledbooleanDisables this item.
Accessibility

Keyboard & ARIA

  • ← / → — Move focus between items.
  • Space / Enter — Toggle pressed state of focused item.
  • Each item renders with aria-pressed reflecting its state.
  • Provide aria-label on icon-only items.
