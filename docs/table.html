Table

A responsive HTML table with semantic sub-components for header, body, footer, rows, cells, and caption. Pair with sorting, selection, row actions, and pagination patterns for full data-table functionality.

Sortable columns

Click any column header to sort. A second click reverses direction. Implemented client-side — production apps typically pass sort state to the server.

Usage — shadcn/ui

# Install via shadcn/ui CLI
npx shadcn@latest add table
import {
  Table,
  TableBody,
  TableCaption,
  TableCell,
  TableFooter,
  TableHead,
  TableHeader,
  TableRow,
} from "@/components/ui/table"

<Table>
  <TableCaption>A list of your recent invoices.</TableCaption>
  <TableHeader>
    <TableRow>
      <TableHead>Invoice</TableHead>
      <TableHead>Status</TableHead>
      <TableHead className="text-right">Amount</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    {invoices.map((inv) => (
      <TableRow key={inv.id}>
        <TableCell className="font-medium">{inv.id}</TableCell>
        <TableCell>{inv.status}</TableCell>
        <TableCell className="text-right">{inv.amount}</TableCell>
      </TableRow>
    ))}
  </TableBody>
  <TableFooter>
    <TableRow>
      <TableCell colSpan={2}>Total</TableCell>
      <TableCell className="text-right">$2,390.00</TableCell>
    </TableRow>
  </TableFooter>
</Table>

// Responsive — wrap in a scrollable container
<div className="relative w-full overflow-auto">
  <Table>{/* ... */}</Table>
</div>

Props

All sub-components accept standard HTML element attributes in addition to className for Tailwind overrides.

ComponentHTML elementKey attributesNotes
Table<table>aria-labelAlways provide an accessible label when there is no visible caption.
TableHeader<thead>—Sticky positioning via sticky top-0 Tailwind class when needed.
TableBody<tbody>—Renders row hover and selection styles via TableRow.
TableFooter<tfoot>—Muted background; use for totals or summary rows.
TableRow<tr>data-state="selected"Adds a selected background when data-state is "selected".
TableHead<th>scope, aria-sortSet aria-sort="ascending" / "descending" / "none" on sortable columns.
TableCell<td>colSpan, rowSpanUse className="text-right font-medium" for numeric/currency cells.
TableCaption<caption>—Renders below the table by default (caption-side: bottom).

Accessibility

FeatureBehavior
aria-label on tableRequired when no TableCaption is visible. Screen readers announce it before reading the table structure.
scope="col"shadcn/ui adds this automatically to <th> elements to associate each header with its column.
aria-sortSet to "ascending", "descending", or "none" on sortable TableHead buttons. Update it on click.
Sort buttonUse a native <button> inside TableHead — not a <div> with onclick — so keyboard users can activate it with Enter / Space.
Checkbox select-allUse aria-label="Select all rows" on the header checkbox and aria-label="Select row" on each row checkbox. Set indeterminate state when some (not all) rows are selected.
data-state="selected"Add to TableRow when a row is selected; this applies the selected background and is announced by AT as a state change.
Row actionsIcon-only action buttons must have aria-label or a visually-hidden text label — icon alone is not accessible.
Keyboard navigationStandard Tab order across interactive elements (checkboxes, sort buttons, action buttons). For full grid keyboard navigation, use role="grid" with → / ← cell navigation.
Empty stateUse a single row with colSpan equal to the total column count so the table structure remains valid and screen readers don't skip the empty message.
Responsive scrollWrap in overflow-x: auto. Do not truncate or hide columns — horizontal scroll is preferable to data loss.
