Select

A styled dropdown for choosing one option from a list. Built on Radix UI's Select primitive — keyboard-navigable, accessible, and fully themed with design tokens. Prefer Select over the native <select> for consistent cross-browser appearance.

Usage — shadcn/ui

# Install via shadcn/ui CLI
npx shadcn@latest add select
import {
  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectLabel,
  SelectSeparator,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select"

// Basic
<Select>
  <SelectTrigger className="w-[180px]">
    <SelectValue placeholder="Select a fruit…" />
  </SelectTrigger>
  <SelectContent>
    <SelectItem value="apple">Apple</SelectItem>
    <SelectItem value="banana">Banana</SelectItem>
    <SelectItem value="blueberry">Blueberry</SelectItem>
  </SelectContent>
</Select>

// Grouped with labels & separator
<Select>
  <SelectTrigger className="w-[240px]">
    <SelectValue placeholder="Select timezone…" />
  </SelectTrigger>
  <SelectContent>
    <SelectGroup>
      <SelectLabel>North America</SelectLabel>
      <SelectItem value="est">EST — New York</SelectItem>
      <SelectItem value="pst">PST — Los Angeles</SelectItem>
    </SelectGroup>
    <SelectSeparator />
    <SelectGroup>
      <SelectLabel>Europe</SelectLabel>
      <SelectItem value="gmt">GMT — London</SelectItem>
      <SelectItem value="cet">CET — Paris</SelectItem>
    </SelectGroup>
  </SelectContent>
</Select>

// Controlled
const [value, setValue] = useState("")

<Select value={value} onValueChange={setValue}>
  {/* trigger + content */}
</Select>

// With disabled item
<SelectItem value="enterprise" disabled>Enterprise</SelectItem>

Accessibility

FeatureBehavior
role="combobox"The trigger has role="combobox" and aria-haspopup="listbox" — announces to screen readers that activating it opens a list.
aria-expandedSet to true / false on the trigger as the dropdown opens or closes.
role="listbox"SelectContent has role="listbox"; each SelectItem has role="option".
aria-selectedThe currently selected item gets aria-selected="true"; all others are false.
aria-disabledDisabled items have aria-disabled="true" so screen readers skip them in the option count.
Label associationAlways wrap with a <label htmlFor> pointing to the SelectTrigger id, or use aria-label / aria-labelledby on the Select root.
Keyboard — triggerSpace / Enter / ↓ open the dropdown; Esc closes it and restores focus to the trigger.
Keyboard — items↑ / ↓ navigate items; Home / End jump to first/last; Enter selects the focused item.
Type-aheadTyping a character jumps to the first item whose label starts with that letter.
Focus trapWhile the dropdown is open, focus is trapped within the listbox. Background content is not reachable by keyboard.
