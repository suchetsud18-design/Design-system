Progress

Displays an indicator showing the completion progress of a task, typically displayed as a progress bar. Built on Radix UI Progress.

Accessibility

ARIA

  • Renders with role="progressbar", aria-valuemin, aria-valuemax, and aria-valuenow automatically.
  • When value is null, aria-valuenow is omitted (indeterminate).
  • Provide an aria-label or aria-labelledby to describe what is being tracked.
