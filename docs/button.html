Button

Triggers an action or event. Six variants, four sizes, icon-only mode, and a loading state — all built on a native <button> with full keyboard and focus support.

Variants

Each variant maps to a distinct token pair and signals a different level of emphasis.

Default

Primary action — highest emphasis.

Destructive

Irreversible or dangerous actions.

Outline

Secondary action alongside a Default.

Secondary

Neutral, supporting actions.

Ghost

Lowest emphasis — no chrome until hover.

Link
Learn more →

Inline navigation — looks like a text link.

Usage — shadcn/ui

# Install via shadcn/ui CLI
npx shadcn@latest add button
import { Button } from "@/components/ui/button"

// Variants
<Button>Default</Button>
<Button variant="destructive">Delete</Button>
<Button variant="outline">Outline</Button>
<Button variant="secondary">Secondary</Button>
<Button variant="ghost">Ghost</Button>
<Button variant="link">Link</Button>

// Sizes
<Button size="sm">Small</Button>
<Button size="lg">Large</Button>
<Button size="icon" aria-label="Settings">
  <Settings className="h-4 w-4" />
</Button>

// With icon
<Button>
  <Download className="h-4 w-4" />
  Download
</Button>

// As link (asChild)
import { Link } from "next/link"

<Button asChild>
  <Link href="/dashboard">Go to dashboard</Link>
</Button>

// Loading state (combine with disabled)
<Button disabled>
  <Loader2 className="h-4 w-4 animate-spin" />
  Saving…
</Button>

Accessibility

PatternGuidance
KeyboardEnter and Space trigger the button. Focus is shown via the :focus-visible ring (2px offset, 4px ring).
Icon-onlyAlways provide aria-label on icon-only buttons — the label is announced instead of the SVG title.
Loading stateSet disabled and add aria-busy="true" while loading. Update label text to "Saving…" so screen readers describe the pending state.
asChild linkWhen rendered as <a>, the element gains native link semantics. Avoid role="button" on anchors — use a real <button> for non-navigation actions.
DisabledThe disabled prop sets pointer-events:none and opacity. For form buttons that should remain visible to screen readers when unavailable, consider aria-disabled="true" without the disabled attribute.
Color contrastDefault: white on #171717 = 16.1:1. Destructive: white on #dc2626 = 5.25:1. Secondary: #171717 on #f5f5f5 = 15.1:1. All meet WCAG AA.
