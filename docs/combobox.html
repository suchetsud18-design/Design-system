API Reference

The Combobox is a pattern — not a single component. It composes Popover and Command. The props below document each relevant piece.

Popover (trigger + positioner)

PropTypeDefaultDescription
openboolean—Controlled open state of the popover.
onOpenChange(open: boolean) => void—Callback fired when the open state changes.
defaultOpenbooleanfalseUncontrolled initial open state.
modalbooleanfalseWhen true, interaction outside the popover is blocked.

PopoverTrigger

PropTypeDefaultDescription
asChildbooleanfalseMerge trigger props onto its child element instead of a default button.

Command (search + list container)

PropTypeDefaultDescription
valuestring—The currently selected value (controlled).
onValueChange(value: string) => void—Called when selected value changes.
filter(value: string, search: string) => numberbuilt-inCustom filter function. Return a score from 0 (no match) to 1 (full match).
shouldFilterbooleantrueSet to false to manage filtering externally (e.g. async search).
loopbooleanfalseWhen true, keyboard navigation loops from last to first item and vice versa.

CommandInput

PropTypeDefaultDescription
placeholderstring—Placeholder text shown when the search field is empty.
valuestring—Controlled search input value.
onValueChange(value: string) => void—Fires on every keystroke in the search field.

CommandItem

PropTypeDefaultDescription
valuestring—The value used for filtering and selection. Must be unique within the list.
onSelect(value: string) => void—Callback when the item is selected (click or Enter).
disabledbooleanfalsePrevents selection and removes from keyboard navigation.

Usage

"use client" import * as React from "react" import { Check, ChevronsUpDown } from "lucide-react" import { cn } from "@/lib/utils" import { Button } from "@/components/ui/button" import { Command, CommandEmpty, CommandGroup, CommandInput, CommandItem, CommandList, } from "@/components/ui/command" import { Popover, PopoverContent, PopoverTrigger, } from "@/components/ui/popover" const frameworks = [ { value: "next.js", label: "Next.js" }, { value: "sveltekit", label: "SvelteKit" }, { value: "nuxt.js", label: "Nuxt.js" }, { value: "remix", label: "Remix" }, { value: "astro", label: "Astro" }, ] export function ComboboxDemo() { const [open, setOpen] = React.useState(false) const [value, setValue] = React.useState("") return ( <Popover open={open} onOpenChange={setOpen}> <PopoverTrigger asChild> <Button variant="outline" role="combobox" aria-expanded={open} className="w-[200px] justify-between" > {value ? frameworks.find((f) => f.value === value)?.label : "Select framework..."} <ChevronsUpDown className="ml-2 h-4 w-4 shrink-0 opacity-50" /> </Button> </PopoverTrigger> <PopoverContent className="w-[200px] p-0"> <Command> <CommandInput placeholder="Search framework..." /> <CommandList> <CommandEmpty>No framework found.</CommandEmpty> <CommandGroup> {frameworks.map((framework) => ( <CommandItem key={framework.value} value={framework.value} onSelect={(currentValue) => { setValue(currentValue === value ? "" : currentValue) setOpen(false) }} > <Check className={cn( "mr-2 h-4 w-4", value === framework.value ? "opacity-100" : "opacity-0" )} /> {framework.label} </CommandItem> ))} </CommandGroup> </CommandList> </Command> </PopoverContent> </Popover> ) }

Accessibility

Keyboard & ARIA

  • Enter / Space — open the popover when focus is on the trigger button
  • ↑ / ↓ — navigate between items in the list; Command handles this automatically
  • Enter — select the focused item
  • Escape — close the popover without selection
  • Tab — moves focus out of the popover, closing it
  • The trigger button carries role="combobox", aria-expanded, and aria-haspopup="listbox"
  • The list carries role="listbox"; each item carries role="option" and aria-selected
  • The search input receives focus automatically when the popover opens
  • Selected state is communicated visually (checkmark) and via aria-selected="true"
  • Use shouldFilter={false} with async data sources to ensure screenreaders receive accurate result counts
