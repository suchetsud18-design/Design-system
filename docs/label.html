Label

Renders an accessible label associated with controls. Built on the native HTML <label> element with enhanced styling and peer-disabled support.

Preview

Usage
import { Label } from "@/components/ui/label" <Label htmlFor="email">Email</Label> <Input id="email" type="email" />

Accessibility

Keyboard & ARIA

  • The htmlFor attribute links the label to its input via id.
  • Clicking a label transfers focus to and activates its associated control.
  • When the associated input is disabled, the label automatically renders at reduced opacity via peer-disabled:opacity-50.
  • Screen readers announce the label text when the associated input receives focus.
