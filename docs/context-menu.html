Context Menu

Displays a menu to the user — such as a set of actions or functions — triggered by a right-click or long press. Built on Radix UI Context Menu.

Accessibility

Keyboard & ARIA

  • ↑ / ↓ — Move focus between menu items.
  • Enter / Space — Activate the focused item.
  • Escape — Close the context menu.
  • → — Open a submenu.
  • Menu uses role="menu"; items use role="menuitem", role="menuitemcheckbox", or role="menuitemradio".
