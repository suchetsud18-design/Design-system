Accessibility

Usage notes

  • HoverCard is for supplementary, non-critical content — do not place required actions inside it.
  • It only opens on hover/focus — keyboard users can access it via focus.
  • Content is announced by screen readers when the card opens.
  • For critical actions on hover, use Popover instead (click-triggered, focus-trapped).
