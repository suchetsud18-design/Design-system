Component

Drawer

A drawer component for React that is built on top of Vaul. Slides in from the bottom of the screen on mobile, similar to a native bottom sheet.

Accessibility

Keyboard & ARIA

  • Escape — Close the drawer.
  • Focus is trapped inside the drawer while open.
  • Renders with role="dialog" and aria-modal="true".
  • The drag handle is decorative; the DrawerClose button provides a programmatic close action.
