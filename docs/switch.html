Switch

A control that allows the user to toggle between checked and unchecked states. Built on Radix UI Switch with full keyboard and ARIA support.

Accessibility

Keyboard & ARIA

  • Space — Toggle the switch when focused.
  • Renders with role="switch" and aria-checked reflecting the current state.
  • When disabled, aria-disabled="true" is set and interaction is blocked.
  • Associate with a Label via htmlFor / id for screen reader announcement.
