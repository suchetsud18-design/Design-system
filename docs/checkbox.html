Checkbox

A control that allows the user to toggle between checked and not checked. Supports default, subtext, disabled, and card variants.

Default

Click any checkbox to toggle its state. The box is 16×16px with a 6px border-radius from Figma.

API Reference

Checkbox

PropTypeDefaultDescription
checked boolean | 'indeterminate' — The controlled checked state. Use with onCheckedChange.
defaultChecked boolean false The uncontrolled default checked state.
onCheckedChange (checked: boolean | 'indeterminate') => void — Callback fired when the checked state changes.
disabled boolean false Prevents interaction and applies 0.5 opacity to the row.
required boolean false Marks the checkbox as required in a form context.
name string — The name submitted with form data.
value string "on" The value submitted with form data when checked.
id string — Links the checkbox to a <label> via htmlFor.
asChild boolean false Merge props onto the immediate child element (Radix UI pattern).

Usage

import { Checkbox } from "@/components/ui/checkbox" import { Label } from "@/components/ui/label" // Basic <div className="flex items-center gap-2"> <Checkbox id="terms" /> <Label htmlFor="terms">Accept terms and conditions</Label> </div> // Controlled const [checked, setChecked] = React.useState(false) <Checkbox checked={checked} onCheckedChange={setChecked} /> // Indeterminate (partial selection) <Checkbox checked="indeterminate" /> // Disabled <Checkbox disabled /> <Checkbox disabled defaultChecked />

Accessibility

Keyboard & Screen Reader

  • Space — toggles the checkbox between checked and unchecked
  • Tab / Shift+Tab — moves focus to / from the checkbox
  • The Radix UI primitive renders a visually hidden <input type="checkbox">, ensuring native form submission and screen reader compatibility
  • aria-checked="true", aria-checked="false", or aria-checked="mixed" for the three states
  • aria-disabled="true" on the input when disabled is set
  • Always pair with a visible <Label> or aria-label — never leave a checkbox without an accessible name
  • Focus ring uses var(--ring) with a 2px outline and 2px offset, meeting WCAG 2.4.11
