Accessibility

Usage notes

  • All scrollable regions are natively keyboard accessible.
  • Scroll Area preserves native keyboard scrolling (arrow keys, Page Up/Down, Home/End).
  • The custom scrollbar is decorative; native scroll behavior is preserved underneath.
  • Screen readers interact with the content directly, not the custom scrollbar.
