Alert Dialog

A modal dialog that interrupts the user with important content and expects a response. Built on Radix UI AlertDialog — traps focus, blocks interaction with background content, and supports keyboard dismissal.

Preview

Click the trigger to see a live Alert Dialog. Press Esc or Cancel to dismiss.

Default — confirmation dialog
Destructive — dangerous action
In-context — dialog with backdrop (static)

Are you absolutely sure?

This action cannot be undone. This will permanently delete your account and remove your data from our servers.

Variants

Alert Dialog supports two primary use cases: confirmation and destructive actions.

Default

Are you sure?

This action cannot be undone.

Destructive

Delete account

All data will be permanently removed.

Usage — shadcn/ui

# Install via shadcn/ui CLI
npx shadcn@latest add alert-dialog
import {
  AlertDialog,
  AlertDialogAction,
  AlertDialogCancel,
  AlertDialogContent,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogHeader,
  AlertDialogTitle,
  AlertDialogTrigger,
} from "@/components/ui/alert-dialog"
import { Button } from "@/components/ui/button"

export function AlertDialogDemo() {
  return (
    <AlertDialog>
      <AlertDialogTrigger asChild>
        <Button variant="outline">Open</Button>
      </AlertDialogTrigger>
      <AlertDialogContent>
        <AlertDialogHeader>
          <AlertDialogTitle>Are you absolutely sure?</AlertDialogTitle>
          <AlertDialogDescription>
            This action cannot be undone. This will permanently
            delete your account and remove your data.
          </AlertDialogDescription>
        </AlertDialogHeader>
        <AlertDialogFooter>
          <AlertDialogCancel>Cancel</AlertDialogCancel>
          <AlertDialogAction>Continue</AlertDialogAction>
        </AlertDialogFooter>
      </AlertDialogContent>
    </AlertDialog>
  )
}

For destructive actions, apply the destructive variant to AlertDialogAction:

<AlertDialogAction
  className="bg-destructive text-white hover:bg-destructive/90"
>
  Delete Account
</AlertDialogAction>

Accessibility

Alert Dialog is a WAI-ARIA alertdialog modal — it traps focus and blocks all background interaction until dismissed.

FeatureBehavior
role="alertdialog"Announces as a modal alert; screen readers immediately describe the dialog title and description.
Focus trapTab / Shift+Tab cycle only within the dialog while open. Background elements are inert.
EscCloses the dialog and restores focus to the trigger element. Note: Esc does not close AlertDialog by default in shadcn — only explicit Cancel/Action buttons dismiss it, to prevent accidental dismissal.
aria-labelledbyAutomatically wired to AlertDialogTitle by Radix UI.
aria-describedbyAutomatically wired to AlertDialogDescription by Radix UI.
Scroll lockBody scroll is locked while the dialog is open via Radix scroll-area utility.
Focus restorationOn close, focus returns to the element that triggered the dialog.

Always pair AlertDialogTitle and AlertDialogDescription — do not omit the description for dialogs requesting destructive or irreversible actions.
