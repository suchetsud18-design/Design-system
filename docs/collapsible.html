Collapsible

An interactive component which expands/collapses a panel. One item is always visible; additional items are revealed by toggling the trigger.

Default

Exact Figma layout — a bordered card with a title row, a permanently visible item, and two additional items behind the toggle.

Collapsible (Root)

PropTypeDefaultDescription
open boolean — Controlled open state. Use with onOpenChange.
defaultOpen boolean false Uncontrolled initial open state.
onOpenChange (open: boolean) => void — Callback when open state changes.
disabled boolean false Prevents toggling when true.
asChild boolean false Merge props onto immediate child (Radix UI pattern).

CollapsibleTrigger

PropTypeDefaultDescription

PropTypeDefaultDescription

Accessibility

Keyboard & ARIA

  • Enter / Space — toggle the collapsible open or closed when focus is on the trigger
  • Tab — move focus into and through the collapsible content when open
  • The trigger is a native <button> — aria-expanded="true" / aria-expanded="false" reflects open state
  • aria-controls on the trigger links to the content region's id
  • The content region uses role="region" with an accessible label (linked via aria-labelledby on the trigger)
  • Content remains interactive when open — focus is not trapped
  • Use forceMount if you need the content indexed by search engines or assistive tech even when closed
