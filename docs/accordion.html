Usage — shadcn/ui

Install the component then import the primitives directly.

# Install via shadcn/ui CLI
npx shadcn@latest add accordion
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/ui/accordion"

export function AccordionDemo() {
  return (
    <Accordion type="single" collapsible className="w-full">
      <AccordionItem value="item-1">
        <AccordionTrigger>Product Information</AccordionTrigger>
        <AccordionContent>
          Our flagship product combines cutting-edge technology
          with sleek design.
        </AccordionContent>
      </AccordionItem>

      <AccordionItem value="item-2">
        <AccordionTrigger>Shipping Details</AccordionTrigger>
        <AccordionContent>
          Standard delivery takes 3–5 business days.
        </AccordionContent>
      </AccordionItem>

      <AccordionItem value="item-3">
        <AccordionTrigger>Return Policy</AccordionTrigger>
        <AccordionContent>
          30-day hassle-free returns with free return shipping.
        </AccordionContent>
      </AccordionItem>
    </Accordion>
  )
}

Props

Component Prop Type Default Description
Accordion type "single" | "multiple" — Whether one or many items can be open simultaneously.
Accordion collapsible boolean false Allow all items to be closed when type="single".
Accordion defaultValue string | string[] — The item value(s) open by default (uncontrolled).
Accordion value string | string[] — Controlled open item(s). Pair with onValueChange.
AccordionItem value string — Unique identifier for this item.
AccordionItem disabled boolean false Prevents the user from interacting with the item.
AccordionTrigger asChild boolean false Merge props onto the child element (Radix slot pattern).

Accessibility

Built on Radix UI Accordion, which implements the WAI-ARIA Accordion pattern.

KeyAction
Space / EnterToggle the focused accordion item
TabMove focus to the next trigger
Shift + TabMove focus to the previous trigger
↓Move focus to the next trigger (when focus is on a trigger)
↑Move focus to the previous trigger
HomeMove focus to the first trigger
EndMove focus to the last trigger
