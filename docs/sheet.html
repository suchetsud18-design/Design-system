Component

Sheet

Extends the Dialog component to display content that complements the main content of the screen. Slides in from the edge of the screen. Built on Radix UI Dialog.

Preview
Right side sheet (default)
Side variants
Use cases
Edit profile Shopping cart Notifications Settings panel
Edit profile
Make changes to your profile here. Click save when you're done.
Usage
import { Sheet, SheetContent, SheetDescription, SheetHeader, SheetTitle, SheetTrigger, } from "@/components/ui/sheet" <Sheet> <SheetTrigger asChild> <Button variant="outline">Open</Button> </SheetTrigger> <SheetContent> <SheetHeader> <SheetTitle>Edit profile</SheetTitle> <SheetDescription> Make changes to your profile here. </SheetDescription> </SheetHeader> </SheetContent> </Sheet>

Accessibility

Keyboard & ARIA

  • Escape — Close the sheet and return focus to the trigger.
  • Focus is trapped inside the sheet while open.
  • Renders with role="dialog", aria-modal="true", and aria-labelledby pointing to the title.
  • The overlay click closes the sheet (configurable).
