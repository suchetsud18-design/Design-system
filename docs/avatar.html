Avatar

An image element with a fallback for representing a user. Supports circular and square shapes, multiple sizes, initials/icon fallbacks, status indicators, and grouped stacking.

Usage
import { Avatar, AvatarImage, AvatarFallback } from "@/components/ui/avatar"

// Basic with image + initials fallback
<Avatar>
  <AvatarImage src="/avatars/jane.jpg" alt="Jane Doe" />
  <AvatarFallback>JD</AvatarFallback>
</Avatar>

// Larger size
<Avatar className="size-16">
  <AvatarImage src="/avatars/jane.jpg" alt="Jane Doe" />
  <AvatarFallback className="text-xl">JD</AvatarFallback>
</Avatar>

// Square (workspace / team logos)
<Avatar className="rounded-lg">
  <AvatarImage src="/team.jpg" alt="Team" />
  <AvatarFallback className="rounded-lg">TM</AvatarFallback>
</Avatar>
Props

Avatar — root container (built on Radix UI Avatar.Root)

PropTypeDefaultDescription
classNamestring—Additional Tailwind classes. Use size-* to override dimensions, rounded-lg for square variant.
asChildbooleanfalseMerge props onto a child element instead of rendering a <span>.

AvatarImage — the <img> element (Radix UI Avatar.Image)

PropTypeDefaultDescription
srcstring—Image URL. Triggers fallback if empty, broken, or still loading.
altstring—Required for accessibility. Describe the person or entity shown.
onLoadingStatusChangefunction—Callback fired with "loading" | "loaded" | "error".

AvatarFallback — shown when image is absent or broken (Radix UI Avatar.Fallback)

PropTypeDefaultDescription
classNamestring—Override fallback background, text colour, or border-radius.
delayMsnumber0Delay (ms) before fallback renders — prevents flash on fast networks.
asChildbooleanfalseMerge props onto a child element.

Accessibility
ConcernGuidance
Alt textAlways provide a descriptive alt on AvatarImage — e.g. the person's name. If purely decorative, use alt="".
Fallback contentInitials must be visible text (not icon-only) for screen readers. Icon-only fallbacks should include a visually-hidden label or aria-label.
Status indicatorsStatus dots are purely visual. Pair with a visually-hidden <span> or title attribute describing the presence state.
Avatar groupWrap in a role="list" element and give each avatar role="listitem" for coherent screen-reader enumeration.
ContrastInitials text must meet WCAG AA (4.5:1) against the fallback background. Use the token-based palette which is pre-validated.
Interactive avatarsIf clicking navigates to a profile, wrap in <a> or <button> and ensure a visible focus ring via focus-visible:ring-2.
Image load flashUse delayMs on AvatarFallback (e.g. 600) so the fallback doesn't flash on fast connections.
