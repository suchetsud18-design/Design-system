Command

Fast, composable, unstyled command menu for React. Built on top of cmdk by Paco Coursey. Press ⌘J anywhere on this page to open the live demo.

Accessibility

Keyboard & ARIA

  • ⌘J / Ctrl J — conventional shortcut to open the command palette (implement via useEffect + keydown listener)
  • ↑ / ↓ — navigate between items; focus wraps when loop is enabled
  • Enter — select the currently focused item
  • Escape — close the dialog or clear the search field
  • Home / End — jump to the first or last visible item
  • The root carries role="combobox" with aria-expanded and aria-haspopup="listbox"
  • The list carries role="listbox"; each item carries role="option"
  • CommandDialog wraps content in a Radix Dialog — provides role="dialog", aria-modal="true", focus trapping, and scroll lock automatically
  • Groups auto-hide their heading when all child items are filtered out — screenreaders will not announce empty groups
  • Use CommandShortcut for visual hints only — actual keyboard shortcuts must be registered separately
  • Provide an aria-label on CommandInput when the surrounding dialog title is not descriptive enough
