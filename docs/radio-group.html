Radio Group

A set of checkable buttons — known as radio buttons — where no more than one of the buttons can be checked at a time. Built on Radix UI Radio Group.

Usage

Accessibility

Keyboard & ARIA

  • ↑ / ↓ — Move between radio buttons (vertical).
  • ← / → — Move between radio buttons (horizontal).
  • Container has role="radiogroup"; each item has role="radio" with aria-checked.
  • Pair each RadioGroupItem with a Label for screen reader announcement.
