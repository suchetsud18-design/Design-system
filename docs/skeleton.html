Skeleton

Use to show a placeholder while content is loading. Renders an animated shimmer effect that matches the shape of the incoming content.

Usage
import { Skeleton } from "@/components/ui/skeleton" <Skeleton className="w-[100px] h-[20px] rounded-full" /> // Card skeleton <div className="flex items-center space-x-4"> <Skeleton className="h-12 w-12 rounded-full" /> <div className="space-y-2"> <Skeleton className="h-4 w-[250px]" /> <Skeleton className="h-4 w-[200px]" /> </div> </div>

Accessibility

Usage notes

  • Skeleton is purely visual — wrap it in a container with aria-label="Loading..." or role="status" to announce loading state.
  • Use aria-busy="true" on the parent container while content loads, then remove it when content is ready.
  • Match skeleton shapes to the actual content to reduce layout shift (CLS).
