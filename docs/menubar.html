Accessibility

Keyboard & ARIA

  • ← / → — Move between menu triggers in the menubar.
  • ↑ / ↓ — Move between items in an open menu.
  • Escape — Close the open menu and return focus to the trigger.
  • The menubar uses role="menubar"; each trigger has role="menuitem"; menus have role="menu".
