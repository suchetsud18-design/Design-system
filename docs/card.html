Usage — shadcn/ui

# Install via shadcn/ui CLI
npx shadcn@latest add card
import {
  Card,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"

export function CardDemo() {
  return (
    <Card>
      <CardHeader>
        <CardTitle>Create project</CardTitle>
        <CardDescription>
          Deploy your new project in one-click.
        </CardDescription>
      </CardHeader>
      <CardContent>
        {/* Your content */}
      </CardContent>
      <CardFooter className="flex justify-between">
        <Button variant="outline">Cancel</Button>
        <Button>Deploy</Button>
      </CardFooter>
    </Card>
  )
}

// Stat card — no footer, horizontal header
<Card>
  <CardHeader className="flex-row items-center justify-between">

    <p className="text-3xl font-bold">$45,231.89</p>
    <p className="text-xs text-muted-foreground">
      +20.1% from last month
    </p>
  </CardContent>
</Card>

Props

All sub-components are thin wrappers that extend HTMLDivElement.

ComponentElementDefault classesDescription
Card<div>rounded-xl border bg-card shadow-smRoot container. Accepts any div props.
CardHeader<div>flex flex-col space-y-1.5 p-6Top section — typically holds title and description.
CardTitle<h3>font-semibold leading-none tracking-tightPrimary heading. Semantically <h3> — override with asChild if needed.
CardDescription<p>text-sm text-muted-foregroundSupporting subtitle beneath the title.
CardContent<div>p-6 pt-0Main body area — no top padding by default (header provides it).
CardFooter<div>flex items-center p-6 pt-0Bottom action row — no top padding by default.

Accessibility

PatternGuidance
Heading levelCardTitle renders as <h3>. Adjust with asChild + <h2> or <h4> to match the page outline — don't skip heading levels.
Interactive cardsIf the entire card is clickable, use a wrapping <a> or add role="button" with keyboard handlers. Avoid placing multiple interactive elements inside an already-clickable card.
Landmark regionsIn dashboards with many metric cards, wrap groups in a <section aria-label="…"> to create navigable landmarks for screen readers.
Decorative imagesHero images in card headers should use alt="" (empty alt) if the image is purely decorative — the title already describes the card.
Focus orderInteractive elements in CardFooter receive focus in DOM order. Ensure Cancel precedes Submit in the DOM to match the visual left-to-right order.
