Alert

Displays a callout for user attention. Built on shadcn/ui with design tokens from Figma — supports default and destructive variants with optional description and list content.

Preview

All three variants from Figma — Default, Title Only, and Destructive.

Usage — shadcn/ui

# Install via shadcn/ui CLI
npx shadcn@latest add alert
import { Alert, AlertTitle, AlertDescription } from "@/components/ui/alert"
import { CheckCircle } from "lucide-react"

// Default variant
export function AlertDemo() {
  return (
    <Alert>
      <CheckCircle className="h-4 w-4" />
      <AlertTitle>Success!</AlertTitle>
      <AlertDescription>
        Your changes have been saved.
      </AlertDescription>
    </Alert>
  )
}

// Destructive variant
export function AlertDestructive() {
  return (
    <Alert variant="destructive">
      <AlertCircle className="h-4 w-4" />
      <AlertTitle>Error</AlertTitle>
      <AlertDescription>
        Your session has expired. Please log in again.
      </AlertDescription>
    </Alert>
  )
}

Accessibility

Alert is a non-interactive landmark — it announces its content to assistive technologies on render.

AttributeValuePurpose
role"alert"Triggers an immediate ARIA live announcement for critical messages.
role="status"OverrideUse for informational / non-critical callouts (polite announcement).
aria-liveImplied by role="alert"Assertive — screen readers interrupt the current reading context.
IconDecorative — aria-hiddenIcon is hidden from screen readers; meaning is conveyed in text.

For dynamic alerts injected after page load, ensure the Alert component is present in the DOM before content is set — some screen readers only announce role="alert" content when it appears inside a pre-existing container.
