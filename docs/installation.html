Getting Started

Installation

Set up the design system in a new or existing Next.js project. The process takes about five minutes.

Prerequisites

  • Node.js
    JavaScript runtime
    ≥ 18.17
  • Next.js
    React framework (App Router)
    ≥ 14.0
  • Tailwind CSS
    Utility-first CSS framework
    ≥ 3.4

Quick start

1
Create a Next.js project

Start with a fresh Next.js app using the App Router, TypeScript, and Tailwind CSS. Skip this step if you have an existing project.

bash
npx create-next-app@latest my-app \
  --typescript \
  --tailwind \
  --eslint \
  --app \
  --src-dir \
  --import-alias "@/*"

cd my-app
2
Initialize shadcn/ui

Run the shadcn init command. When prompted, choose Neutral as the base color and Yes for CSS variables — our token file is built around this configuration.

bash
npx shadcn@latest init
When asked "Which style would you like to use?" select Default. When asked for base color, select Neutral. When asked about CSS variables, select Yes.
3
Add components

Install the components you need. You can add them one at a time or in bulk. Each component is copied into your components/ui/ folder so you own the code entirely.

bash
# Add individual components
npx shadcn@latest add button card input

# Or add all 43 components at once
npx shadcn@latest add --all
4
Copy design-tokens.css

Copy design-tokens.css from this repository into your project. Place it in src/styles/ or any folder that makes sense for your structure.

my-app/
├── src/
│   ├── app/
│   │   ├── globals.css
│   │   └── layout.tsx
│   ├── components/
│   │   └── ui/
│   └── styles/
│       └── design-tokens.css   ← copy here
└── tailwind.config.ts
5
Replace the generated CSS variables

Open src/app/globals.css. The shadcn init command added a :root { ... } block with basic CSS variables. Replace that entire block by importing our token file instead — it provides a complete, richer superset of those variables.

csssrc/app/globals.css
@import '../styles/design-tokens.css';

@tailwind base;
@tailwind components;
@tailwind utilities;

/* Remove the :root { ... } and .dark { ... } blocks
   that shadcn init generated — design-tokens.css
   provides these, plus 450+ additional tokens. */
Delete the entire :root { ... } and .dark { ... } blocks that shadcn init created. Our token file already includes both light and dark mode definitions with higher fidelity values.
6
(Optional) Extend Tailwind config

If you want Tailwind utilities to reference the design tokens directly (e.g., text-primary, bg-muted), add the token aliases to your Tailwind config.

typescripttailwind.config.ts
import type { Config } from 'tailwindcss'

export default {
  content: ['./src/**/*.{ts,tsx}'],
  theme: {
    extend: {
      colors: {
        background:  'hsl(var(--background))',
        foreground:  'hsl(var(--foreground))',
        primary: {
          DEFAULT:    'hsl(var(--primary))',
          foreground: 'hsl(var(--primary-foreground))',
        },
        muted: {
          DEFAULT:    'hsl(var(--muted))',
          foreground: 'hsl(var(--muted-foreground))',
        },
        destructive: {
          DEFAULT:    'hsl(var(--destructive))',
        },
        border:  'hsl(var(--border))',
        input:   'hsl(var(--input))',
        ring:    'hsl(var(--ring))',
      },
      borderRadius: {
        sm:   'var(--radius-sm)',
        md:   'var(--radius-md)',
        lg:   'var(--radius-lg)',
        xl:   'var(--radius-xl)',
        full: 'var(--radius-full)',
      },
      fontFamily: {
        sans: ['var(--font-sans)'],
        mono: ['var(--font-mono)'],
      },
    },
  },
  plugins: [],
} satisfies Config
7
Use a component

Import a shadcn/ui component and use it in any page or layout. The design tokens are applied automatically — no className overrides needed.

tsxsrc/app/page.tsx
import { Button }   from '@/components/ui/button'
import { Card, CardContent, CardHeader, CardTitle } from '@/components/ui/card'

export default function Page() {
  return (
    <Card>
      <CardHeader>
        <CardTitle>Hello</CardTitle>
      </CardHeader>
      <CardContent>
        <Button>Get started</Button>
        <Button variant="outline">Learn more</Button>
      </CardContent>
    </Card>
  )
}

Run npm run dev and open http://localhost:3000. You should see the components styled with the design system tokens.

Useful shadcn CLI commands

Command Description

npx shadcn@latest add --allAdd all available components
npx shadcn@latest diffCheck for upstream component updates
npx shadcn@latest diff [component]See what changed in a specific component

Keeping tokens in sync

When the Figma file is updated and a new design-tokens.css is exported, updating your project is a single file replace. No component code changes are needed — every component reads from the CSS custom properties automatically.

The token file is self-contained: it defines both :root (light mode) and :root.dark / :root[data-theme="dark"] (dark mode) in a single import. See Theming for how dark mode is wired up.
