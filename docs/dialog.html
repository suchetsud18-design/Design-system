Dialog

A window overlaid on the primary content, rendering below-content inert. Dismissible via the Esc key, the close button, or clicking the backdrop — unlike Alert Dialog which requires an explicit choice.

Dialog vs Alert Dialog

Choose based on whether the action requires a forced decision.

✓ Use Dialog when…
  • Collecting input (edit, create, filter forms)
  • Showing details or a preview
  • Sharing or copying a link
  • The user can abandon the action without consequence
  • Clicking the backdrop or pressing Esc is a safe dismiss
✗ Use Alert Dialog when…
  • Confirming a destructive or irreversible action
  • The user must explicitly choose Cancel or Confirm
  • Accidental backdrop-click would cause data loss
  • The action has significant side effects

Usage — shadcn/ui

# Install via shadcn/ui CLI
npx shadcn@latest add dialog
import {
  Dialog,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "@/components/ui/dialog"
import { Button } from "@/components/ui/button"
import { Input } from "@/components/ui/input"
import { Label } from "@/components/ui/label"

export function DialogDemo() {
  return (
    <Dialog>
      <DialogTrigger asChild>
        <Button variant="outline">Edit Profile</Button>
      </DialogTrigger>
      <DialogContent className="sm:max-w-[425px]">
        <DialogHeader>
          <DialogTitle>Edit profile</DialogTitle>
          <DialogDescription>
            Make changes to your profile here.
          </DialogDescription>
        </DialogHeader>
        <div className="grid gap-4 py-4">
          <div className="grid grid-cols-4 items-center gap-4">
            <Label htmlFor="name" className="text-right">Name</Label>
            <Input id="name" defaultValue="Jordan Davies" className="col-span-3" />
          </div>
        </div>
        <DialogFooter>
          <Button type="submit">Save changes</Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  )
}

// Controlled (open state managed externally)
const [open, setOpen] = useState(false)

<Dialog open={open} onOpenChange={setOpen}>
  {/* trigger + content */}
</Dialog>

Accessibility

FeatureBehavior
role="dialog"Identifies the panel as a dialog to screen readers; less urgent than alertdialog — does not interrupt reading context.
aria-modal="true"Informs AT that content outside is inert while the dialog is open.
aria-labelledbyAuto-wired by Radix to DialogTitle.
aria-describedbyAuto-wired by Radix to DialogDescription.
Focus trapTab / Shift+Tab cycle only within the dialog. Background elements are not reachable by keyboard.
EscCloses the dialog and restores focus to the trigger. Prevent with onEscapeKeyDown={e => e.preventDefault()} if form data could be lost.
Backdrop clickCloses the dialog by default. Prevent with onInteractOutside={e => e.preventDefault()} for unsaved-changes scenarios.
Focus restorationOn close, focus returns to the element that triggered the dialog.
Initial focusFirst focusable element inside DialogContent receives focus on open. Override with onOpenAutoFocus to focus a specific field.
Scroll lockBody scroll is locked while the dialog is open.
